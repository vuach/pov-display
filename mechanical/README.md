# Механическая часть

## Измеренные данные

| Элемент | Данные |
|---|---|
| Двигатель A2212/13T | корпус Ø27,81 мм; вал Ø3,17 мм |
| Вал относительно монтажной плоскости | начало 29,5 мм; конец 40,6 мм |
| Монтажные отверстия двигателя | 2 × Ø2,65 мм; межосевое расстояние 32,8 мм |
| TX-катушка | Ø42,4 / 20,3 мм; толщина 2,3 мм; плата 18 × 10,2 × 3 мм |
| RX-катушка | Ø43 / 20,2 мм; толщина 1,2 мм; плата 14 × 27,7 × 4,4 мм |
| Зазор катушек | 3 мм |
| Адаптер | прижимные поверхности Ø12,1 и Ø12,7 мм |
| LED-ветвь | 20 APA102, длина 140 мм |

## Компоновка

Неподвижная часть включает основание, стойку, двигатель, TX-катушку и
защитный кожух. Вращающаяся часть включает ступицу, RX-катушку, PCB-R2,
две LED-ветви и Hall. Три фазных провода двигателя образуют связку шириной
8 мм в канале стойки; питание TX проходит отдельной двухжильной линией.

Печатные детали относятся к корпусу, держателям катушек, кольцу и направляющим.
Несущая ступица, силовая балка и прозрачный экран относятся к металлическим/
поликарбонатным деталям. Испытание вращением механической сборки не выполнено.
