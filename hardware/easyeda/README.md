# EasyEDA

`pov-display-schematic-rev-a.json` — историческая двухлистовая схема стендовой Rev A, в которой MP1584 расположен до кольца. Для односторонней платы ротора Rev B актуальна архитектура с MP1584 на роторе из `docs/architecture-and-wiring.md` и `hardware/pcb/rotor-controller-rev-b-home-etch.md`; Rev A нельзя использовать как монтажную схему Rev B.

`pov-display-electrical-draft.json` — старый структурный черновик. Он сохранён только как обзор архитектуры и не должен использоваться вместо принципиальной схемы.

`exports/pov-display-schematic-rev-a.pdf` — читаемый экспорт Rev A. Исходный JSON обновлён до правила «20 LED по умолчанию, 21 после измерения» позднее PDF-экспорта; после проверки полученной ленты PDF требуется повторно экспортировать из EasyEDA. Электрическая распиновка от этого уточнения не меняется.

Схема предназначена для проверки архитектуры и соединений. Она не является производственной: библиотечные посадочные места, номиналы предохранителей, параметры кольца, полярность разъёмов и маркировку реальных модулей требуется проверить до изготовления.

Ограничение графических примитивов относится только к `pov-display-electrical-draft.json`. В Rev A электрические выводы и цепи присутствуют, однако ERC ещё не считается пройденным: условные символы требуется заменить проверенными библиотечными компонентами, назначить корпуса и сверить номера выводов с полученными деталями.

Основная схема генерируется командой:

```powershell
& "C:\Users\vuach\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" "hardware/easyeda/generate-schematic.js"
```

Генератор структурного черновика: `generate-draft.js`.

После генерации файл импортируется через `Файл → Открыть → EasyEDA`.

Карта замены графических блоков компонентами библиотеки и собственными символами приведена в `library-replacement-map.md`.
