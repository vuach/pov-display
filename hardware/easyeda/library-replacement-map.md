# Замена графических блоков компонентами EasyEDA

Названия библиотечных элементов могут немного различаться между локальной и веб-версиями EasyEDA. Поиск следует выполнять по английским ключевым словам. До выбора посадочного места требуется сверить реальную деталь штангенциркулем и по маркировке.

## Лист 01 — Stationary Power

| Блок | Что установить | Поиск в библиотеке | Контакты и замечания |
|---|---|---|---|
| `J1 Li-Po 3S` | Двухконтактный разъём | `XT60`, при отсутствии — `CONN_01X02` | 1 — `VBAT+`, 2 — `GND_STATOR`. Пол разъёма выбрать по фактической батарее. |
| `F1 MAIN FUSE` | Предохранитель | `FUSE` | Номинал пока `TBD`. Для внешнего держателя посадочное место не назначать либо вывести два контакта. |
| `SW1 DC SWITCH` | Однополюсный выключатель | `SW_SPST` | Только DC-rated выключатель или anti-spark узел. |
| `ESC1 ESC 30 A` | Собственный символ ESC либо три разъёма | `CONN_01X02`, `CONN_01X03` | Питание: `BAT+`, `BAT-`; двигатель: `U`, `V`, `W`; управление: `PWM`, `GND`, `BEC_5V`. `BEC_5V` оставить `NC`, пока схема питания не подтверждена. |
| `M1 A2212 1000KV` | Трёхфазный двигатель | `MOTOR_BLDC`, `BRUSHLESS MOTOR`; при отсутствии — `CONN_01X03` | Контакты `U`, `V`, `W`. Направление меняется перестановкой любых двух фаз. |
| `F2 LOGIC FUSE` | Предохранитель | `FUSE` | Предварительно 3 A; окончательный номинал после нагрузочного теста. |
| `U1 MP1584 DC-DC` | Собственный символ модуля на 4 вывода | `MP1584 MODULE`; если найден только `MP1584EN`, его не использовать вместо готовой платы | `IN+`, `IN-`, `OUT+`, `OUT-`. Для схемы допустим собственный символ без PCB footprint. |
| `C1` | Полярный электролитический конденсатор 100 мкФ, не менее 25 В | `CP`, `CAP POLARIZED` | Между `VBAT+` и `GND_STATOR`, рядом со входом MP1584. |
| `C2` | Полярный электролитический конденсатор 220 мкФ, не менее 10 В | `CP`, `CAP POLARIZED` | Между `+5V_STATOR` и `GND_STATOR`, рядом с выходом MP1584. |
| `SR1` | Разъём 1×6 либо собственный символ кольца | `CONN_01X06` | 1–2: `+5V`; 3–4: `GND`; 5: `ESC_PWM`; 6: `BEEP_CTRL/NC`. Footprint не нужен, если кольцо подключается проводами. |
| `JROTOR` | Разъём жгута питания ротора, если он физически предусмотрен | `CONN_01X04` | 1–2: `+5V_ROTOR`; 3–4: `GND_ROTOR`. Если отдельного разъёма не будет, блок удалить и соединить кольцо непосредственно с шинами. |
| `J5 ESC PWM RETURN` | Не отдельный компонент, а имя цепи | `NETLABEL` | Использовать метку `ESC_PWM`; отдельный разъём нужен только при разъёмном жгуте. |
| `R6` | Резистор 1 кОм | `R`, `RESISTOR` | Между `BEEP_CTRL` и базой Q1. |
| `Q1` | NPN-транзистор | `2N3904` или фактически купленный `S8050` | Эмиттер — GND, коллектор — минус динамика, база — через R6. Footprint выбирать строго по корпусу и распиновке конкретного транзистора. |
| `BZ1` | Активный зуммер 5 В | `BUZZER`, `ACTIVE BUZZER` | Плюс — `+5V_STATOR`, минус — коллектор Q1. Для электромагнитного зуммера добавить обратный диод; для пьезоактивного обычно не требуется. |

## Лист 02 — Rotor Logic

| Блок | Что установить | Поиск в библиотеке | Контакты и замечания |
|---|---|---|---|
| `U3 ESP32 DevKit V1` | Готовый символ `ESP32 DEVKIT V1 30 PIN` либо собственный 30-контактный модуль | `ESP32 DEVKIT V1`, `DOIT ESP32 DEVKIT V1 30PIN` | Сторонние модели нельзя принимать без проверки. Для текущей схемы нужны `VIN`, `3V3`, `GND`, GPIO18, 19, 22, 23, 25, 26, 27. |
| `U4` | Четырёхканальный буфер `74AHCT125` | `74AHCT125`, `SN74AHCT125N` | Для DIP-корпуса выбрать `DIP-14`. Не заменять на `74HC125`: порог входного уровня отличается. |
| `C3` | Керамический конденсатор 100 нФ | `C`, `CAPACITOR` | Между выводами U4 14 и 7, максимально близко к корпусу. |
| `R1–R4` | Четыре резистора 330–470 Ом | `R`, `RESISTOR` | Ставятся последовательно на выходах U4 возле буфера. |
| `JLA`, `JLB` | Два входных разъёма лопастей 1×4 | `CONN_01X04`; для платы — `JST XH 4P`, например `B4B-XH-A` | Контакты назначить как `+5V`, `GND`, `DATA/DI`, `CLOCK/CI`. Фактический порядок конкретной ленты проверить по надписям и стрелке. |
| `C4`, `C5` | Полярные электролиты 1000 мкФ, не менее 10 В | `CP`, `CAP POLARIZED` | По одному у входа каждой лопасти, между `+5V_ROTOR` и `GND_ROTOR`. |
| `JH1/H1 KY-003` | Собственный символ модуля на 3 вывода либо разъём 1×3 | `CONN_01X03`; для самого датчика можно искать `A3144`, `AH3144` | Для модуля: `-` — GND, `+` — 3V3, `S` — GPIO27. Расположение выводов сверить по надписям на имеющемся модуле. |
| `R5` | Резистор 220 Ом | `R`, `RESISTOR` | GPIO25 → R5 → `ESC_PWM` → канал 5 кольца. |
| `SR1-5`, `SR1-6` | Не отдельные компоненты | `NETLABEL`, `PORT` | Это контакты 5 и 6 единого компонента SR1 на первом листе. Межлистовые связи оформить портами `ESC_PWM` и `BEEP_CTRL`. |

## Распиновка U4 SN74AHCT125N

| Вывод | Назначение в проекте |
|---:|---|
| 1 | `1OE` → GND |
| 2 | `1A` ← GPIO18 |
| 3 | `1Y` → R1 → `DATA_A` |
| 4 | `2OE` → GND |
| 5 | `2A` ← GPIO19 |
| 6 | `2Y` → R2 → `CLOCK_A` |
| 7 | GND |
| 8 | `3Y` → R3 → `DATA_B` |
| 9 | `3A` ← GPIO23 |
| 10 | `3OE` → GND |
| 11 | `4Y` → R4 → `CLOCK_B` |
| 12 | `4A` ← GPIO22 |
| 13 | `4OE` → GND |
| 14 | `VCC` → +5V |

## Символ ESP32, если потребуется создать вручную

Для 30-контактной платы при USB-разъёме снизу подписи на имеющемся экземпляре расположены так:

- левый ряд сверху вниз: `EN`, `VP`, `VN`, `D34`, `D35`, `D32`, `D33`, `D25`, `D26`, `D27`, `D14`, `D12`, `D13`, `GND`, `VIN`;
- правый ряд сверху вниз: `D23`, `D22`, `TX0`, `RX0`, `D21`, `D19`, `D18`, `D5`, `TX2`, `RX2`, `D4`, `D2`, `D15`, `GND`, `3V3`.

Габариты платы, расстояние между рядами и нумерацию выводов для посадочного места требуется снять с реального экземпляра. У 30-контактных клонов DevKit V1 встречаются разные размеры.

## Рекомендуемый порядок перестройки

1. Установить стандартные R, C, FUSE, SW_SPST, Q1 и U4.
2. Все внешние модули временно представить разъёмами.
3. Создать собственные символы `ESP32_DEVKIT_V1_30P`, `MP1584_MODULE`, `ESC_30A` и `SLIP_RING_6CH`.
4. Заменить длинные линии именами цепей и межлистовыми портами.
5. Запустить ERC и отдельно проверить питание, незадействованные выводы и направление входов/выходов.
6. Посадочные места назначать только после измерения реальных деталей.
