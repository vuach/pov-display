# Схемы соединений

- `wiring-netlist.csv` — актуальная таблица соединений для Rev B: через токосъёмное кольцо передаётся `VBAT`, а MP1584 установлен на роторе.
- `system-schematic.svg` и `system-schematic.png` — ранняя обзорная схема Rev A. Она оставлена для истории и не должна использоваться как монтажная схема Rev B.

Актуальные пояснения по монтажу находятся в `../assembly-and-wiring.md`, распиновка кольца — в `../slip-ring-pinout.md`, а односторонняя плата — в `../pcb/rotor-controller-rev-b-home-etch.md`.
