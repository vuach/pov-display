# PCB-S2 Rev C Gerber

Актуальный производственный экспорт неподвижной платы PCB-S2 из комплекта `escGerb`.

- `pcb-s2-rev-c-gerber.zip` — архив для передачи изготовителю;
- остальные файлы — распакованный комплект слоёв, сверловки и проверки.

Редактируемый исходник EasyEDA Pro: `../../easyeda-pro/pcb-s2-rev-c.epro2`.
