# Rotor controller Rev B — home etch

Односторонняя нижняя медь для ручного травления. Компоненты устанавливаются сверху, пайка выполняется снизу. Красные пунктирные соединения на preview выполняются отдельными изолированными проводами сверху.

Печатать `rotor-controller-rev-b-home-etch-bottom-mirrored-1to1.svg` в масштабе 100 %. После печати проверить размер рамки `110 × 70 мм` и примерить ESP32 до травления.

Состав производственного архива:

- `*.GBL` — нижняя медь;
- `*.GKO` — контур платы;
- `*-NPTH.drl` — все отверстия без металлизации;
- `manufacturing.json` — параметры и координаты перемычек;
- `pad-map.csv` — карта площадок;
- `*-preview.svg` и `*-preview.bmp` — монтажный preview;
- `*-bottom-mirrored-1to1.svg` — шаблон тонерного переноса.

Электрическая проверка генератора не заменяет бумажную примерку компонентов, проверку механического крепления и балансировку ротора.
