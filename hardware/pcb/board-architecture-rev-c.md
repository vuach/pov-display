# Платы Rev C

## PCB-S2 — неподвижная плата

Функции PCB-S2: питание стационарного ESP32-C3, питание индуктивного
передатчика, передача PWM на ESC и подключение кнопок ARM/STOP.

| Интерфейс | Состав |
|---|---|
| Питание | Li-Po 3S → внешний предохранитель → D1 → U2/U3 |
| U2 | 5 V для ESP32-C3 |
| U3 | 9 V для передатчика |
| ESC | J3.1 GND, J3.2 BEC_NC, J3.3 PWM от GPIO6 |
| Кнопки | GPIO20 ARM, GPIO21 STOP |

На фактически собранной PCB-S2 снят R1. Линия `GPIO6 → J3.3` реализована
внешней перемычкой. Контакт F1 и путь J1.1 повреждены; стендовый ввод
питания проходит через внешний предохранитель на анод D1.

## PCB-R2 — центральная плата ротора

PCB-R2 имеет статус проектируемой платы. Она содержит ESP32-C3,
SN74AHCT125, вход RX, Hall и интерфейсы двух LED-ветвей.

| Сеть | Назначение |
|---|---|
| `5V_R`, `GND_R` | питание от RX |
| `3V3_R` | питание C3 и Hall |
| `HALL_S` | Hall через подтяжку 10 кОм |
| `LED_DATA_3V3`, `LED_CLK_3V3` | GPIO4/GPIO5 C3 |
| `LED_DATA_5V`, `LED_CLK_5V` | выход SN74AHCT125 через 330 Ом |
| `LEDA_DO`, `LEDA_CO` | переход от LED A к LED B |

Роторная плата и её механическое крепление не изготовлены.
