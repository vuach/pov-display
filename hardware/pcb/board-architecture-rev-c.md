# Платы Rev C

## PCB-S2

PCB-S2 является неподвижным узлом управления и питания. На ней размещены
ESP32-C3, MP1584 U2/U3, D1, конденсаторы и разъёмы.

| Интерфейс | Назначение |
|---|---|
| J2 | питание TX |
| J3.1 | GND ESC |
| J3.2 | BEC не подключён |
| J3.3 | PWM ESC от GPIO6 |
| J4 | 3V3, GND, ARM, STOP |

## Роторная плата

Роторная плата содержит ESP32-C3, SN74AHCT125, Hall-датчик и интерфейс APA102.

| Сеть | Назначение |
|---|---|
| `5V_R`, `GND_R` | питание от RX |
| `HALL_S` | вход Hall |
| `LED_DATA_3V3`, `LED_CLK_3V3` | GPIO4/GPIO5 ESP32-C3 |
| `LED_DATA_5V`, `LED_CLK_5V` | выходы SN74AHCT125 |
