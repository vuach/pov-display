# Монтаж и соединения

Документ задаёт проектную схему соединений. Нумерация контактов модулей и цвета жил кольца подтверждаются на фактических деталях до пайки.

## Неподвижная часть

| Откуда | Куда | Провод | Проверка перед соединением |
|---|---|---|---|
| Li-Po `+` | F1 → выключатель → ESC `+` | 14–16 AWG красный | Полярность, номинал F1, выключатель DC |
| Li-Po `−` | ESC `−` | 14–16 AWG чёрный | Общая земля силовой части |
| После выключателя | F2 → MP1584 `IN+` | По измеренному току | Нет питания при выключенном выключателе |
| Li-Po `−` | MP1584 `IN−` | По измеренному току | Полярность мультиметром |
| MP1584 `OUT+` | Кольцо CH1 и CH2 | Две отдельные жилы | Ровно 5,00 В без нагрузки |
| MP1584 `OUT−` | Кольцо CH3 и CH4 | Две отдельные жилы | Непрерывность земли |
| ESC signal | Кольцо CH5 | 26 AWG | BEC-красный провод не соединён |
| Драйвер звука | Кольцо CH6 | 26 AWG | Только после выбора зуммера |

## Вращающаяся часть

| Откуда | Куда | Назначение |
|---|---|---|
| CH1 + CH2 | Шина `+5V_ROTOR` | Параллельно после прозвонки одинаковых каналов |
| CH3 + CH4 | Шина `GND_ROTOR` | Общая земля ротора |
| `+5V_ROTOR` | ESP32 `VIN`, SN74AHCT125 VCC, обе APA102 | Звёздное питание; не в `3V3` |
| `GND_ROTOR` | Все GND | Единая точка около распределения питания |
| GPIO18 | U4 канал 1 → 330–470 Ом → APA102 A DI | DATA A |
| GPIO19 | U4 канал 2 → 330–470 Ом → APA102 A CI | CLOCK A |
| GPIO23 | U4 канал 3 → 330–470 Ом → APA102 B DI | DATA B |
| GPIO22 | U4 канал 4 → 330–470 Ом → APA102 B CI | CLOCK B |
| GPIO27 | KY-003 OUT | Hall; OUT предварительно измеряется |
| ESP32 3V3 | KY-003 VCC | Не питать Hall от 5 В без проверки модуля |
| GPIO25 | 220 Ом → CH5 → ESC signal | PWM 50 Гц |

Все четыре `/OE` SN74AHCT125 соединяются с GND. Конденсатор 100 нФ размещается непосредственно у выводов 14 и 7 буфера. Электролиты у лопастей устанавливаются с проверенной полярностью.

## Порядок первого включения

1. Не подключать аккумулятор, ESC и мотор.
2. Прозвонить отсутствие короткого замыкания между 5 В и GND.
3. Настроить MP1584 отдельно на 5,00 В.
4. Подключить эквивалент нагрузки, затем кольцо; повторить измерения.
5. Проверить ESP32 от USB отдельно.
6. Проверить Hall от 3,3 В.
7. Проверить одну APA102 при неподвижной конструкции, затем вторую.
8. Проверить две ветви вместе с программным лимитом яркости.
9. Проверить PWM осциллографом без мотора.

JST-XH-подобные корпуса не надеваются непосредственно на гребёнку ESP32, если нужные выводы расположены не подряд. Для финальной сборки применяется переходная плата или закреплённый жгут с индивидуально изолированными контактами.
