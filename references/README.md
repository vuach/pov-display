# Справочные материалы

- `source-documents/` — исходный практикум без правок;
- `component-screenshots/` — фотографии и скриншоты карточек компонентов.

Справочные материалы не являются окончательной спецификацией. Маркировки и размеры физических компонентов имеют приоритет перед изображениями продавцов.
