# Стендовые проверки

Результаты всех физических измерений заносятся в `bring-up-results.md`. Значение `PASS` допускается только после фактической проверки; ожидаемое или расчётное значение результатом не считается.

## Протоколы

1. [Приёмка новых компонентов](components-intake-checklist.md)
2. [ESP32 и общий порядок сборки](../docs/bring-up-plan.md)
3. [Датчик Холла KY-003](ky-003-protocol.md)
4. [Понижающий преобразователь MP1584](mp1584-protocol.md)
5. [Преобразователь уровней SN74AHCT125](sn74ahct125-protocol.md)
6. [Шестиканальное кольцо](slip-ring-protocol.md)
7. [Две APA102 без вращения](apa102-static-protocol.md)
8. [Сигнал ESC без мотора](esc-signal-protocol.md)

Перед каждой проверкой выполняются визуальный осмотр, проверка полярности и контроль отсутствия короткого замыкания. Мотор, ESC и ротор остаются отключёнными.
