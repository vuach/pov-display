# Стендовые проверки

Результаты всех физических измерений заносятся в `bring-up-results.md`. Значение `PASS` допускается только после фактической проверки; ожидаемое или расчётное значение результатом не считается.

## Протоколы

1. [ESP32 и общий порядок сборки](../docs/bring-up-plan.md)
2. [Датчик Холла KY-003](ky-003-protocol.md)
3. [Понижающий преобразователь MP1584](mp1584-protocol.md)

Перед каждой проверкой выполняются визуальный осмотр, проверка полярности и контроль отсутствия короткого замыкания. Мотор, ESC и ротор остаются отключёнными.
