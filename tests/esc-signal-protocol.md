# Проверка сигнала ESC без мотора

## Условия

- мотор отключён от ESC;
- красный провод BEC из трёхконтактного разъёма изолирован;
- земля ESC соединена с общей землёй управления;
- измерение проводится сначала до кольца, затем через CH5;
- `ENABLE_ESC_ACTIVE_TEST=0`.

## Измерение

| Состояние | Частота | Высокий уровень | Результат |
|---|---:|---:|---|
| После сброса ESP32 | 50 Гц | 1000 мкс | — |
| Команда `PWM 1050` при блокировке | 50 Гц | 1000 мкс | — |
| Команда `SAFE` | 50 Гц | 1000 мкс | — |
| Потеря BLE | 50 Гц | 1000 мкс | — |
| Через CH5 кольца | 50 Гц | 1000 мкс, без пропусков | — |

Активный диапазон 1000–1100 мкс этим протоколом не проверяется. Для него нужен отдельный тест с мотором без ротора, закрытым кожухом, аварийным отключением и подтверждённым направлением вращения.
