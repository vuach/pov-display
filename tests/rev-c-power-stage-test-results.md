# Результаты стендовой проверки силовой части Rev C

Дата: 14.10.2026. Проверки выполнялись без адаптера, ротора и лопастей;
мотор был закреплён.

## Итог

Стационарная силовая часть, индуктивное питание под малой нагрузкой и первый
запуск связки ESP32-C3 → ESC → A2212 подтверждены. Рабочие испытания с
вращающимся ротором не проводились.

## Подтверждённые результаты

| Узел | Результат |
|---|---|
| Аккумулятор LiPo 3S | На стенде измерено 11,75–11,8 В. |
| U2 MP1584, питание ESP32-C3 | Настроен на 5 В; на плате измерено 4,95–5,03 В. |
| U3 MP1584, передатчик | Настроен на 9 В; на плате измерено 8,98 В. |
| Передающая катушка | Светодиод передатчика включается; на выходе передатчика измерено 5,31 В. |
| Приёмная катушка | На выходе приёмника измерено 5,25 В; ESP32-C3 запускается. |
| ESP32-C3 | По USB получен статус `STATE=SAFE requested=1000 actual=1000`; 3,3 В измерены как 3,31–3,32 В. |
| PWM ESC | Импульсы 50 Гц проходят по перемычке `GPIO6 → J3.3` (оранжевый провод ESC); на 1000 мкс измеренное среднее напряжение составляло около 0,165 В, что ожидаемо для 5 % заполнения. |
| ESC | Последовательность звуков подтверждает распознавание 3S и безопасного сигнала 1000 мкс. |
| Мотор A2212 | При временном автоматическом импульсе 1200 мкс после взведения ESC мотор запустился и вращался 3 с без ротора и лопастей. |

## Фактическая электрическая конфигурация

- `R1` снят: первоначальный путь `GPIO5 → R1 → J3.3` не используется.
- Сигнал ESC идёт отдельной перемычкой `GPIO6 → J3.3`; земли ESP32 и ESC общие.
- Тонкий красный провод BEC ESC не используется; коричневый провод — GND,
  оранжевый — PWM.
- Контактная площадка/цепь штатного `F1` повреждена. На время стенда питание
  платы подаётся через внешний предохранитель непосредственно к аноду D1;
  `J1.1` не использовать до ремонта платы.
- Моторный ток идёт отдельной толстой ветвью LiPo → предохранитель → ESC,
  а не через PCB-S2 и не через MP1584.

## Не проведено

- длительная нагрузочная проверка MP1584;
- индуктивное питание при токах выше малой нагрузки;
- ручной запуск через ARM/KEEPALIVE в штатном режиме;
- работа с адаптером, ротором, лопастями и защитным кожухом;
- проверка механического баланса и вибрации.

До завершения этих пунктов запрещены испытания с установленными лопастями.
