# Результаты проверки силовой части Rev C

## Измерения

| Узел | Результат |
|---|---|
| Li-Po 3S | 11,75–11,8 V |
| U2 MP1584 | 4,95–5,03 V |
| U3 MP1584 | 8,98 V |
| Передающая катушка | 5,31 V |
| Приёмная катушка | 5,25 V |
| Логическая шина C3 | 3,31–3,32 V |
| PWM ESC | 50 Hz, безопасный импульс 1000 мкс |

## Функциональный результат

Связка Li-Po 3S, PCB-S2, ESP32-C3, ESC, A2212 и индуктивного канала
работоспособна. Двигатель запускается и управляется по PWM. Передача питания
на роторную часть подтверждена.
