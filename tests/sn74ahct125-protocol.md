# Проверка SN74AHCT125 без светодиодных лент

## Цель

Подтвердить преобразование четырёх сигналов ESP32 с 3,3 В до логических уровней, пригодных для APA102 при питании 5 В. APA102 и ESC во время этой проверки отключены.

## Схема стенда

| Вывод U4 | Подключение |
|---:|---|
| 1, 4, 10, 13 (`/OE`) | GND |
| 2 (`1A`) | GPIO18, DATA A |
| 3 (`1Y`) | контроль выхода DATA A |
| 5 (`2A`) | GPIO19, CLOCK A |
| 6 (`2Y`) | контроль выхода CLOCK A |
| 7 | GND |
| 8 (`3Y`) | контроль выхода DATA B |
| 9 (`3A`) | GPIO23, DATA B |
| 11 (`4Y`) | контроль выхода CLOCK B |
| 12 (`4A`) | GPIO22, CLOCK B |
| 14 | стабилизированные 5,00 В |

Керамический конденсатор 100 нФ устанавливается непосредственно между выводами 14 и 7. Земли источника 5 В и ESP32 объединяются. На время проверки выходы 3, 6, 8 и 11 не подключаются к APA102.

## Безопасная последовательность

1. При отключённом питании проверить ключ корпуса и нумерацию выводов DIP-14.
2. Проверить отсутствие короткого замыкания между выводами 14 и 7.
3. На лабораторном источнике установить `5,00 В`, ограничение тока `0,05 А`.
4. Подать питание только на U4 и убедиться, что микросхема не нагревается и источник не входит в ограничение.
5. Подключить общую землю ESP32 и по очереди подать на каждый вход устойчивые уровни 0 и 3,3 В.
6. Измерить соответствующий выход относительно GND.
7. Только после четырёх успешных каналов установить последовательные резисторы 330–470 Ом и подключать одну APA102-ветвь.

## Критерии

| Проверка | PASS |
|---|---|
| Потребление без нагрузки | Нет срабатывания ограничения 0,05 А и нагрева |
| Низкий уровень каждого выхода | Не выше 0,4 В |
| Высокий уровень каждого выхода | Не ниже 4,5 В при питании 5,00 В |
| Реакция каналов | Каждый выход повторяет только свой вход; соседние выходы не переключаются |

Обычный мультиметр подходит только для постоянных уровней. Форму импульсов DATA/CLOCK и выбросы на частоте SPI проверяют осциллографом или логическим анализатором; отсутствие такого прибора фиксируется отдельно и не заменяется визуальной оценкой LED.

## Основание выбора

- APA102: `VIH(min)=0,7×VDD`; при 5 В это 3,5 В.
- SN74AHCT125 при 4,5–5,5 В: `VIH(min)=2,0 В`, поэтому 3,3-вольтовый выход ESP32 распознаётся с запасом.
- 74HC125 не является эквивалентной заменой: его CMOS-порог не даёт такого запаса для 3,3 В.
