# ESP32 POV — итоговая проектная прошивка

> **Совместимость:** эта версия относится к Rev B с одной ESP32 на роторе и двумя независимыми SPI. Для Rev C без токосъёмного кольца её необходимо разделить на неподвижную прошивку ESC и вращающуюся прошивку ESP32-C3 с одной цепочкой из 40 APA102. Текущий бинарный файл для Rev C не применять.

Версия: `1.0.0-project`.

Прошивка содержит полный предусмотренный программный контур устройства: две APA102-лопасти, синхронизацию Hall, BLE/Serial, хранение изображения и безопасный автомат управления ESC.

Слово «итоговая» относится к составу функций и компиляции. Прошивка не прошла испытания на собранном вращающемся устройстве и сама по себе не разрешает запуск ротора.

## Конфигурации сборки

| Environment | POV | Активный ESC | Назначение |
|---|---:|---:|---|
| `esp32dev` | заблокирован | заблокирован | безопасная сборка по умолчанию |
| `esp32dev-final` | включён | доступен после ARM | полнофункциональная проектная сборка, не прошивать до допуска |
| `esc-bench-c3` | отсутствует | ограничен 1000…1200 мкс | первый запуск неподвижного мотора без ротора |

```powershell
cd "C:\Users\vuach\Main Branch\Current\POV Display\firmware"
```

Команда `run` только компилирует. Она ничего не загружает в ESP32.

## Стендовая прошивка ESC Rev C

`esc-bench-c3` — отдельная минимальная прошивка неподвижной ESP32-C3 для
первого запуска A2212 без ротора, адаптера и лопастей. На собранной плате
GPIO5 не используется: R1 снят, а перемычка `GPIO6 → J3.3` подаёт PWM в ESC.
После загрузки PWM всегда начинается с безопасных 1000 мкс.

Чтобы подать тягу, удерживать кнопку `ARM` (`J4.3` замкнут на `J4.2 GND`) и
отправить `ARM`; затем при всё ещё удерживаемой кнопке — `RUN 1030`. Диапазон
ограничен `1000…1200` мкс. `KEEPALIVE` нужен не реже раза в секунду; при его
пропаже, `STOP` или сбросе контроллера PWM возвращается к 1000 мкс.

Команды Serial Monitor 115200: `HELP`, `STATUS`, `ARM`, `RUN 1000..1200`,
`KEEPALIVE`, `STOP`. Порядок подключения и критерии остановки — в
[`../tests/power-stage-bring-up-rev-c.md`](../tests/power-stage-bring-up-rev-c.md).

## Реализовано

- Hall на GPIO27 с отбрасыванием слишком близких импульсов и фильтрацией периода;
- 120 угловых столбцов, 20 LED на лопасть и сдвиг второй лопасти на 180°;
- два аппаратных SPI: GPIO18/19 и GPIO23/22;
- автоматическое гашение APA102 при потере синхронизации;
- изменение яркости и фазового нуля;
- запись отдельных пикселей, заливка кадра и тестовый рисунок;
- сохранение изображения, яркости и фазы во flash с контрольной суммой;
- двухступенчатое ARM-подтверждение ESC;
- плавное изменение PWM, heartbeat и аварии при потере Hall или превышении RPM;
- безопасные 1000 мкс после загрузки, STOP, потери BLE и любой ошибки ESC.

## Команды Serial и BLE

Serial: `115200`, окончание строки LF или CRLF. BLE-устройство называется `POV-Display`; UUID остались совместимыми с ранней версией.

| Команда | Назначение |
|---|---|
| `PING` | проверка связи |
| `VERSION` | версия прошивки |
| `STATUS` | состояние Hall и ESC |
| `HALL`, `ZERO`, `SIMRPM n` | диагностика датчика и расчёта RPM |
| `POVSTATUS`, `ESCSTATUS` | состояние подсистем |
| `ARM`, затем `ARM CONFIRM` за 3 с | двухступенчатое разрешение ESC |
| `THROTTLE n` | целевой PWM 1000…1600 мкс |
| `KEEPALIVE` | продление разрешения ESC; требуется чаще одного раза в секунду |
| `STOP`, `SAFE`, `OFF`, `DISARM` | 1000 мкс и гашение лопастей |
| `RESETFAULT` | перевод аварии обратно в DISARMED |
| `BRIGHT n` | глобальная яркость APA102, 0…31 |
| `PHASE n` | сдвиг фазового нуля в столбцах |
| `IMAGE CLEAR r g b` | заливка кадра цветом |
| `IMAGE PIXEL column radius r g b` | изменение одного пикселя |
| `IMAGE PATTERN` | восстановление диагностического рисунка |
| `IMAGE SAVE`, `IMAGE LOAD` | запись и чтение кадра из flash |
| `IMAGE STATUS` | параметры буфера изображения |

Передача полного кадра выполняется последовательностью `IMAGE PIXEL`, после чего используется `IMAGE SAVE`. Для удобной эксплуатации позже потребуется отдельное приложение-конвертер, но протокол хранения и изменения произвольного кадра уже реализован.

## Автомат ESC

Состояния: `LOCKED → DISARMED → ARM_PENDING → ARMED → RUNNING`. Любое нарушение переводит управление в `FAULT` и немедленно устанавливает 1000 мкс.

Аварийные условия:

- heartbeat отсутствует более 1 с;
- после начала разгона Hall не появился за 3 с;
- при работающем моторе Hall отсутствует более 0,5 с;
- RPM превышает 2600;
- BLE-соединение разорвано.

PWM изменяется ступенями по 5 мкс каждые 20 мс. Эти значения являются консервативной отправной точкой и должны уточняться по реальному ESC и механике.

## Условия перед использованием функциональной сборки

1. Проверить CH5 кольца осциллографом.
2. Проверить лопасти неподвижно и подтвердить правильный порядок цветов.
3. Проверить аварийные переходы ESC без установленного ротора.
4. Выполнить балансировку и установить закрытый кожух.
5. Только после этого отдельно изменить процедуру допуска к прошивке `esp32dev-final`.
