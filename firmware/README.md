# Прошивка

## Состав исходного кода

| Компонент | Статус |
|---|---|
| `src/main.cpp`, `pov_renderer.cpp`, `esc_controller.cpp` | архивная исходная реализация Rev B для ESP32 DevKit; не соответствует текущей аппаратной конфигурации Rev C |
| `src/esc_bench/main.cpp` | стендовая прошивка управления ESC |
| `esc-bench-c3` | актуальная среда PlatformIO для стационарного ESP32-C3 SuperMini |

## Конфигурация стенда Rev C

- GPIO6: PWM ESC через внешнюю перемычку к J3.3;
- GPIO20: ARM;
- GPIO21: STOP;
- частота PWM: 50 Hz;
- безопасное значение: 1000 мкс;
- активный стендовый импульс: 1200 мкс, 3 с в зафиксированном тесте без ротора.

Аппаратный результат стенда зафиксирован в
`tests/rev-c-power-stage-test-results.md`. Роторная прошивка ESP32-C3 для
APA102 и Hall не реализована в текущем дереве исходного кода.
