# Архитектура Rev C

Неподвижная часть получает энергию от Li-Po 3S. ESC питается отдельной
силовой ветвью и управляет двигателем A2212. PCB-S2 формирует питание
стационарной ESP32-C3 и индуктивного передатчика.

Передающая и приёмная катушки размещены соосно. Гальваническая связь между
статором и ротором отсутствует. Приёмник питает шину `5V_R` роторной части.

На роторе ESP32-C3 получает импульс Hall и выводит DATA/CLOCK на
SN74AHCT125. Буфер формирует 5-вольтовые логические уровни для APA102.
Светодиоды объединены в последовательную цепь из двух ветвей по 20 элементов.

## Геометрия катушек

| Катушка | Наружный / внутренний диаметр | Толщина |
|---|---|---:|
| TX | 42,4 / 20,3 мм | 2,3 мм |
| RX | 43,0 / 20,2 мм | 1,2 мм |

Номинальный осевой зазор катушек: 3 мм.
