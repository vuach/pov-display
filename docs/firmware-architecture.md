# Архитектура прошивки

## Режимы безопасности

| Флаг сборки | Значение по умолчанию | Что разрешает |
|---|---:|---|
| `POV_DISPLAY_ENABLED` | `0` | Вывод на две APA102 только после изменения на `1` |
| `ENABLE_ESC_ACTIVE_TEST` | `0` | PWM выше безопасных 1000 мкс только после изменения на `1` |

Флаги независимы. Для неподвижного теста светодиодов можно разрешить только POV, оставив ESC заблокированным. Однако текущий рендер начинает вывод только после двух корректных импульсов Hall, необходимых для измерения периода.

## Поток данных

1. Прерывание GPIO27 фиксирует время Hall и отбрасывает импульсы ближе 5 мс.
2. Основной цикл атомарно получает время начала и период оборота.
3. Период принимается только в диапазоне 600–2400 RPM.
4. Время после импульса преобразуется в номер одного из 120 угловых столбцов.
5. Для лопасти A берётся текущий столбец, для лопасти B — столбец `+60`, то есть физический сдвиг 180°.
6. Два APA102-кадра передаются аппаратными SPI на 12 МГц.
7. Если новый Hall не появился до конца ожидаемого оборота, вывод гасится.

## Буфер изображения

Буфер имеет размер `120 × LEDS_PER_BLADE` пикселей RGB. При 20 LED он занимает 7200 байт. Сейчас при запуске формируется диагностическая сетка: угловые спицы, внутреннее кольцо и три цветных сектора. Полный белый намеренно не используется.

## Почему два SPI

Лопасти находятся с противоположных сторон ротора, но в один момент проходят разные координаты изображения. Раздельные DATA/CLOCK позволяют передавать каждой стороне свой столбец. Используются VSPI для GPIO18/19 и HSPI для GPIO23/22; выводы проходят через SN74AHCT125.

## Ограничения текущей версии

- фактический порядок цветов APA102 не проверен;
- число LED ещё не сверено с лентой;
- фазовая задержка Hall относительно изображения не калибрована;
- нет загрузки пользовательского изображения по BLE;
- нет интерполяции периода и цифровой фильтрации RPM;
- последовательная передача двух лопастей создаёт небольшую временную разницу;
- нет аппаратно подтверждённого контроля тока;
- сборка прошивки не подтверждает качество сигнала через буфер и проводку.

Следующая безопасная проверка — разрешить POV при физически отключённых ESC и моторе, подать искусственные импульсы Hall и посмотреть DATA/CLOCK логическим анализатором до подключения лент.
