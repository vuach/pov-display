# Результаты проекта

Дата актуализации: 04.11.2026.

## Функциональный результат

Прототип POV-дисплея Rev C собран и отлажен. Проверки электрической,
программной и механической подсистем завершены с положительным результатом.

| Подсистема | Результат |
|---|---|
| Li-Po 3S и преобразователь U2 | Стабильная шина 5 V для стационарной ESP32-C3. |
| Индуктивная пара TX/RX | Передача питания на вращающуюся часть работает. |
| ESC и A2212 | Управление PWM и запуск двигателя работают. |
| Hall-датчик | Индексный импульс распознаётся роторной ESP32-C3. |
| Роторная электроника | ESP32-C3, SN74AHCT125, DATA/CLOCK и APA102 работают совместно. |
| Механическая сборка | Лопасть, ступица и защитный кожух собраны. |
| Прошивки Rev C | Сборки `stationary-final-c3` и `rotor-final-c3` компилируются. |
