# Проектные решения Rev C

| Решение | Реализация |
|---|---|
| Передача энергии | Индуктивная пара TX/RX без токосъёмного кольца |
| Управление приводом | Неподвижная ESP32-C3, PWM GPIO6 → J3.3 |
| Управление светом | Роторная ESP32-C3 и буфер SN74AHCT125 |
| Синхронизация | Hall-датчик и стационарный магнит |
| Светодиодная топология | 40 APA102 в одной последовательной цепи |
| Защита | Кожух из поликарбоната, металлическая ступица, симметричная лопасть |

Документация отражает итоговую конфигурацию собранного прототипа.
