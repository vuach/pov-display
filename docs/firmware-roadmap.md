# Состояние разработки прошивки

## Реализовано к 2026-09-24

- R1: Hall, счётчик импульсов, фильтр периода, RPM и статистика отброшенных импульсов;
- R2: две независимые APA102 по двум аппаратным SPI;
- R3: буфер `120 × 20`, сдвиг второй лопасти 180°, фазовая поправка и blackout;
- R4: двухступенчатый ARM, плавный PWM, heartbeat, предел RPM, контроль потери Hall и аварийный останов;
- R5: произвольное изменение кадра командами, контрольная сумма и сохранение во flash;
- BLE и Serial используют один обработчик команд;
- безопасная и полнофункциональная конфигурации успешно компилируются.

## Не относится к написанию кода

Проектная реализация не становится эксплуатационной до завершения следующих физических работ:

1. Проверка PWM через токосъёмное кольцо.
2. Калибровка фазового нуля на собранном роторе.
3. Измерение минимального устойчивого PWM конкретного ESC и мотора.
4. Подтверждение реального ограничения RPM.
5. Испытание всех аварийных остановов без лопастей.
6. Статическая и динамическая балансировка.
7. Испытание в закрытом кожухе.

## Возможные улучшения после стендовых испытаний

- двоичный BLE-протокол для быстрой загрузки полного кадра;
- приложение-конвертер PNG/текста в 120 угловых столбцов;
- двойная буферизация изображения;
- адаптивная фильтрация RPM по реальному сигналу Hall;
- журнал причин остановки с сохранением во flash.
