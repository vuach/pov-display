# Матрица верификации

`PASS` обозначает выполненную функциональную проверку. Числовые значения
измерений приведены в протоколах `tests/`.

| ID | Объект | Состояние | Основание |
|---|---|---|---|
| V-01 | Питание ESP32-C3 | PASS | 3,31–3,32 V |
| V-02 | U2 MP1584 | PASS | 4,95–5,03 V |
| V-03 | U3 MP1584 | PASS | 8,98 V |
| V-04 | Индуктивный канал TX/RX | PASS | передача питания на ротор |
| V-05 | Hall KY-003 | PASS | индексный импульс |
| V-06 | APA102 и SN74AHCT125 | PASS | DATA/CLOCK и индикация |
| V-07 | PWM ESC | PASS | 50 Hz, безопасное состояние 1000 мкс |
| V-08 | A2212 | PASS | запуск и управление ESC |
| V-09 | Роторная сборка | PASS | совместная работа питания, Hall и LED |
| V-10 | Защитный кожух | PASS | механическая сборка завершена |
