# Спецификация POV-дисплея Rev C

## Назначение

Устройство формирует изображение вращением двух симметричных радиальных
светодиодных ветвей. Начало кадра задаётся Hall-датчиком по одному импульсу за
оборот.

## Состав

| Подсистема | Исполнение |
|---|---|
| Привод | A2212/13T 1000 KV, ESC 30 A, Li-Po 3S 1500 мА·ч |
| Неподвижная часть | ESP32-C3 SuperMini, PCB-S2, MP1584 и передающая катушка |
| Вращающаяся часть | приёмная катушка, ESP32-C3, SN74AHCT125, Hall-датчик |
| Индикация | 40 APA102: две последовательные ветви по 20 LED |
| Механика | металлическая ступица, фанерная лопасть 3 мм, защитный кожух |

## Электрическая структура

```text
Li-Po 3S ── ESC ── A2212
     │
     └─ PCB-S2 ── TX )) RX ── 5V_R ── ESP32-C3 / SN74AHCT125 / APA102
```

Стационарная ESP32-C3 формирует PWM ESC по GPIO6. Роторная ESP32-C3 передаёт
DATA и CLOCK через SN74AHCT125; Hall-датчик подключён к GPIO6 роторного
контроллера.
