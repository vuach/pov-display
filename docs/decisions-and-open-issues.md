# Проектные решения и незакрытые вопросы

Дата актуализации: 19.10.2026.

## Принятые решения

| Решение | Основание |
|---|---|
| Отказ от токосъёмного кольца | Допуск доступного кольца по оборотам не подтверждён. |
| Индуктивная передача питания | На ротор передаётся 5 V через коаксиальную пару катушек. |
| ESP32-C3 на неподвижной части | C3 управляет ESC; фактический PWM использует GPIO6. |
| Отдельный C3 на роторе | Роторная логика располагается рядом с APA102 и Hall. |
| Одна последовательная цепь APA102 | Две ветви по 20 LED соединяются линиями DO/CO в центре. |
| SN74AHCT125 | Буфер обеспечивает 5-вольтовые DATA/CLOCK для APA102. |
| Механическая защита | Поликарбонатный кожух и металлическая ступица входят в обязательный состав. |

## Незакрытые вопросы

| ID | Вопрос | Влияние |
|---|---|---|
| O-01 | Допустимый непрерывный ток индуктивного канала | Яркость и число разрешённых LED-режимов |
| O-02 | Конструкция металлической ступицы и прижим лопасти | Прочность и балансировка |
| O-03 | Масса компонентов ротора | Статический и динамический баланс |
| O-04 | Роторная PCB-R2 и второй ESP32-C3 | Управление APA102 и Hall |
| O-05 | Частотный режим A2212 с реальной нагрузкой | Граница эксплуатационных RPM |
| O-06 | Прочность кожуха | Безопасность вращательных испытаний |
