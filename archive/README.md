# Архив

- `legacy-docs/` — шесть уникальных файлов прежней англоязычной документации;
- `legacy-schematics/` — прежние HTML/PNG-схемы для одной LED-линии;
- `source-notes/` — исходный журнал анализа.

Эти файлы сохранены для истории, но не должны использоваться как инструкция по сборке. Актуальные решения находятся в `docs/`, `hardware/` и `mechanical/`.
