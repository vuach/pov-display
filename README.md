# POV Display

Учебный прототип двухлопастного POV-дисплея с адресными светодиодами APA102.
Питание вращающейся части передаётся через коаксиальную индуктивную пару;
скользящие контакты в конфигурации Rev C отсутствуют.

## Зафиксированная конфигурация Rev C

- двигатель: A2212/13T, 1000 KV;
- аккумулятор: Li-Po 3S, 1500 мА·ч;
- неподвижный контроллер: ESP32-C3 SuperMini;
- сигнал ESC: GPIO6 через отдельную перемычку на `J3.3`;
- индуктивное питание: передатчик от `9 V`, приёмник `5 V`;
- ротор: две противоположные LED-ветви по 20 APA102, последовательно по
  DATA/CLOCK;
- логика ротора: отдельный ESP32-C3, буфер SN74AHCT125 и Hall-датчик;
- защитная конструкция: закрытый поликарбонатный кожух, стационарный магнит
  Hall и отдельная металлическая ступица.

## Состояние

Стационарная плата, индуктивное питание малой мощности и запуск
ESP32-C3 → ESC → A2212 без ротора подтверждены стендовыми измерениями.
Механическая часть ротора, PCB-R2, работа LED на вращении и испытание в
кожухе не подтверждены. Фанерный контур лопасти имеет статус
низкооборотного макета для примерки и балансировки.

## Содержание репозитория

- `docs/` — текущая спецификация, статус, архитектура, матрица верификации и FMEA;
- `hardware/` — ведомость компонентов, силовой расчёт, PCB-S2 и netlist;
- `mechanical/` — измерения, крепление, CAD корпуса и роторный шаблон;
- `firmware/` — архивная исходная POV-прошивка Rev B и стендовая прошивка C3;
- `tests/` — журналы проведённых испытаний;
- `references/` — исходные справочные материалы.
