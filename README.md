# ESP32 POV Display

Двухлопастной POV-дисплей на ESP32 с синхронизацией по датчику Холла.

## Текущая конфигурация

- две симметричные лопасти с активной длиной до 150 мм;
- по 20 APA102 на лопасть в первой сборке; до 21 после измерения;
- ESP32 DevKit V1 на роторе;
- шестиканальное токосъёмное кольцо;
- A2212 1000KV для первого прототипа, 1400KV не использовать;
- аккумулятор и ESC остаются на неподвижном основании;
- в односторонней Rev B модуль MP1584 расположен на роторе, через кольцо передаётся VBAT;
- целевой диапазон после механической валидации: 600–2400 RPM.

Проект пока находится на стадии стендовой проверки электроники. Вращение с установленным ротором запрещено до завершения расчёта, балансировки и изготовления закрытого защитного кожуха.

## Структура

- `docs/` — актуальная спецификация, архитектура, план сборки и безопасность;
- `hardware/` — BOM, расчёт питания, кольцо, разъёмы и двухлистовая принципиальная схема EasyEDA;
- `hardware/pcb/board-architecture.md` — окончательное функциональное разделение двух пользовательских плат и количество отверстий;
- `mechanical/` — требования к ротору, схема крепления мотора/ротора и предварительная параметрическая CAD-модель;
- `firmware/` — итоговая проектная прошивка, безопасная конфигурация по умолчанию и отдельно компилируемая полнофункциональная конфигурация;
- `tests/` — протоколы и результаты испытаний;
- `references/` — исходный практикум и фотографии компонентов.

## Ближайший этап

Автономные стендовые проверки полученных компонентов завершены без выявленных проблем. После получения кольца выполнить его прозвонку и нагрузочный тест. Сборка и вращение ротора остаются запрещены до завершения механического крепления, балансировки и защитного кожуха.
