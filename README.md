# POV Display Rev C

Учебный прототип двухлопастного POV-дисплея с адресными светодиодами APA102.
Питание вращающейся части передаётся бесконтактно индуктивной парой. Скользящие
контакты в Rev C не применяются.

## Итоговая конфигурация

- привод: A2212/13T 1000 KV, ESC 30 A, Li-Po 3S 1500 мА·ч;
- неподвижный контроллер: ESP32-C3 SuperMini, PWM ESC — GPIO6;
- питание ротора: коаксиальная индуктивная пара TX/RX;
- роторный контроллер: ESP32-C3 SuperMini, SN74AHCT125 и Hall-датчик;
- индикация: 40 APA102, две последовательные ветви по 20 LED;
- механика: металлическая ступица, симметричная лопасть и защитный кожух.

## Результат работы

Собранная система Rev C прошла функциональную отладку. Подтверждена работа
питания, бесконтактной передачи энергии, управления ESC и двигателем,
Hall-синхронизации, преобразователя уровней и светодиодной ленты. Итоговые
прошивки для стационарной и вращающейся ESP32-C3 собираются в PlatformIO.
